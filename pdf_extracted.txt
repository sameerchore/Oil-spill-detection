4. MODULE A — SAR DETECTION  AND CHARACTERISATION  
================================================================================  
4.1 Data 
- Zenodo: 
Part I 10.5281/zenodo.8346860  oil train/val  1200 2048x2048x2  Sigma0 dB TIFF 
Part II 10.5281/zenodo.8253899  look-alike + oil-free 
Part III 10.5281/zenodo.13761290  test 150 per class 
- Masks are often NOT georeferenced. ALWAYS copy transform/CRS from the SAR TIFF 
onto the mask before any lat/lon math. 
- Relabel:  
oil folder mask 1 -> class 2 
look-alike folder mask 1 -> class 1 
oil-free -> all 0 
- Training subset for hackathon: 400 oil, 250 look -alike, 150 empty, 512 tiles, 
overlap 64, ignore tiles with <50 oil pixels unless empty class. 
 
4.2 Inference  
- Pad/tile 512, softmax, stitch by max/average  
- Keep class 2 connected  components  area >= 0.05 km2 (or 500 px if no scale) 
- Look-alikes (class 1) drawn yellow on map, excluded from AIS attribution  
- Conﬁdence  = mean oil softmax inside polygon 
 
4.3 Geometry (EPSG:4326  -> local meters via pyproj aeqd at centroid)  
- area_km2,  perimeter_km  
- length_km  = max pairwise distance on polygon exterior simpliﬁed  
- orientation_deg  = PCA of polygon coords (0-180) 
- compactness  = 4*pi*area/perimeter^2  
- centroid lat/lon 
- Export GeoJSON FeatureCollection  
 
4.4 Age 
- Do NOT estimate chemical weathering.  
- After hindcast,  age_hours_proxy  = hours between origin median timestamp  and t_sat. 
- UI label: "Estimated  time since origin (drift proxy), not lab age" 
 
================================================================================  
5. MODULE B — METOCEAN HINDCAST / FORECAST 
================================================================================  
5.1 Field lookup 
function velocity(lat, lon, t): 
u_c, v_c = interp current 
u_w, v_w = interp 10m wind 
alpha = 0.03  
# wind vector: meteorological u/v already toward -east / toward -north 
return u_c + alpha*u_w,  v_c + alpha*v_w  

=== PAGE 8 ===
5.2 Integrator  
- Convert deg to metres with local aeqd, step, convert back 
- Euler OK; RK2 preferred  
- Particles  seeded in oil polygon (or 1 km disk around centroid if polygon tiny) 
- Backward:  dt negative 
- Store hourly mean track + 50/90 percent envelope polygons 
 
5.3 Origin deﬁnition  
- origin_time = time when ensemble median speed relative to AIS search is used 
Default:  time of maximum compactness  of ensemble  OR last hindcast  hour 
FROZEN RULE: origin_time  = t_sat - H hours where H is chosen by 
"ﬁrst time ensemble  spread radius exceeds 8 km" clipped to [6h, 48h], 
AND also return the full track so judges see the path. 
- origin_zone  = 90% envelope at origin_time,  buffered 2 km 
- ALWAYS show uncertainty.  Never a single 400 m pin unless synthetic  planted spill. 
 
5.4 Forecast  
- Same ensemble forward forecast_hours  
- Return GeoJSON cone + list of hourly centroids  
 
5.5 Metocean  ﬁles for demo 
Create THREE cached boxes covering demo scenes (Arabian Sea / Bay of Bengal / 
generic mid-ocean). Each 2-degree tile, hourly, 4 days. 
Generator  script may CALL Open-Meteo once while online: 
https://api.open -meteo.com/v1/forecast  wind_speed_10m, wind_direction_10m 
https://marine -api.open -meteo.com/v1/marine  ocean_current_velocity, ocean_current  
Convert direction/speed  to u,v. Save NetCDF/JSON.  Runtime reads ﬁles only.
